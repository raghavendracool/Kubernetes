# Learning Modules

These folders contain concepts only. Application source code is deliberately kept out of this section.

Each module contains:

- `README.md` — structured What/Why/Where and teaching flow
- `DETAILED-NOTES.md` — topic-specific explanation
- `COMMANDS.md` — command sheet
- `LAB.md` — hands-on exercise
- `examples/` — only small YAML examples required to demonstrate the concept

Complete Modules 01–10 before the kubeadm cluster build, then continue Modules 11–21 while operating the cluster.
