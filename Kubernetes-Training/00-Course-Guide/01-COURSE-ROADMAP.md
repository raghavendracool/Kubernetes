# Course Roadmap

## Phase 1 — Kubernetes Fundamentals

1. Kubernetes Foundation
2. Kubernetes Architecture
3. kubectl, Contexts and Cluster Inspection
4. Kubernetes YAML and API Objects
5. Pods and Pod Lifecycle
6. ReplicaSets, Deployments, Rollouts and Rollbacks
7. Labels, Selectors, Annotations and Namespaces
8. Services, DNS and Service Discovery
9. ConfigMaps and Secrets
10. Probes, Resources and QoS

## Phase 2 — Production Building Blocks

11. Storage: Volumes, PV, PVC and StorageClass
12. StatefulSet, DaemonSet, Job and CronJob
13. Scheduling: nodeSelector, affinity, taints and tolerations
14. ServiceAccounts and RBAC
15. Kubernetes Networking and CNI
16. NetworkPolicy
17. Ingress, Gateway Concepts and TLS
18. Autoscaling, Availability and PDB
19. Helm
20. Monitoring, Logging and Troubleshooting
21. Kubernetes Security and Day-2 Operations

## Phase 3 — Cluster Administration

- Local lab for quick practice
- Self-managed kubeadm cluster on EC2 to simulate on-premises administration
- Amazon EKS managed Kubernetes

## Phase 4 — Application Deployment

Applications are completely separated from the concept modules:

- App 01: Nginx Training Web App
- App 02: Python Flask API
- App 03: Three-Tier Store Demo

## Phase 5 — End-to-End Projects

- Project 01: Build a kubeadm cluster and deploy an application
- Project 02: Build an EKS environment and deploy a production-style application
