# Applications — Kept Separate from Learning Modules

This folder contains actual application code and manifests. The module folders do not duplicate these applications.

- `App-01-Nginx-Training-Web` — basic container + Deployment + Service.
- `App-02-Python-Flask-API` — health checks, configuration, resources, HPA, PDB and rollouts.
- `App-03-Three-Tier-Store` — frontend + API + PostgreSQL StatefulSet/PVC for advanced training.

Use applications only after learning the corresponding Kubernetes objects.
