# Object Cheat Sheet

| Requirement | Object |
|---|---|
| Smallest schedulable workload | Pod |
| Replicated stateless app | Deployment |
| Stable network endpoint | Service |
| Non-sensitive config | ConfigMap |
| Sensitive config | Secret |
| Storage request | PVC |
| Storage catalog/provisioning class | StorageClass |
| Per-node agent | DaemonSet |
| Stable stateful identity | StatefulSet |
| Batch task | Job |
| Scheduled task | CronJob |
| Workload identity | ServiceAccount |
| API authorization | RBAC |
| HTTP routing | Ingress |
| Pod autoscaling | HPA |
| Disruption protection | PDB |
| Pod network rules | NetworkPolicy |
